## 이런 영상

검은 배경 위에 흰 선과 원·사각형·점선이 문구에 맞춰 계속 형태를 바꾸고, 민트색이 강조로만 등장.

## 재현 프롬프트

```
검은 배경에 흰색 선과 단순한 도형(원, 사각형, 점선)만 써서
세로 숏폼 비율의 임팩트 있는 15초 [주제: 동기부여] 모션그래픽 영상을 만들어줘.
포인트 컬러는 [민트] 하나만. 영어 문구와 음악을 넣어줘.
```

## 바꿔 쓸 곳

- 주제, 포인트 컬러, 문구 언어. 한글로 바꿔도 도형 조합만으로 광고 톤이 나온다.

## 잘 된 이유

- 색(흑백 + 1색)과 형태(기본 도형)를 좁게 묶어 어느 모델에서도 세련되게 나온다.
- 도형이 문구 내용에 맞춰 바뀌도록 모델이 알아서 리듬을 쪼갠다.
