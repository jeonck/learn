## 이런 영상

광택 3D 카드 덱이 펼쳐지는 장면을 블렌더로 렌더해 2D 모션그래픽 위에 합성한 서비스 홍보 쇼릴.

## 재현 프롬프트

스레드에 공개된 축약본의 구성 요소로 다시 쓰면:

```
[서비스명]을 알리는 15초 3D 모션 쇼릴을 만들어 주세요.
- 스펙: 1920×1080, 60fps MP4, [BPM] BPM 8마디
- 3D: 블렌더로 광택 카드 [N]장([라벨1]·[라벨2]·[라벨3]·[라벨4])이 펼쳐지는 장면을 투명 배경 시퀀스로 렌더하고, 2D 모션그래픽 위에 합성
- 팔레트: [종이색]·[잉크색]·[강조1]·[강조2]·[강조3] 다섯 색만
- 샷 순서: 훅 → 3D 덱 → 다운로드 → 도장 → 모자이크 → 체크 → 몽타주 → 엔드 카드
- 화면 문구는 "[헤드라인]"과 "[서브 문구]" 두 개만 쓰고 다른 문장은 만들지 말 것
- 음악과 효과음은 박자에 맞춰 새로 합성
- 렌더 후 프레임을 직접 확인하고 고칠 것
```

## 바꿔 쓸 곳

- 서비스명, 카드 라벨, 팔레트, 문구 두 줄. 샷 이름은 서비스 흐름(발견 → 선택 → 받기 → 확인)에 맞게 바꾼다.
- 블렌더가 없으면 3D 덱 대신 CSS/WebGL 3D 카드로 바꿔 달라고 한다.

## 잘 된 이유

- **시간을 박자로**: BPM·마디를 주면 모든 컷이 음악 그리드 위에 놓인다.
- **샷 리스트 = 스토리보드**: 명사 8개가 구성 고민을 없앤다.
- **팔레트를 역할로 제한**, **문구를 못박아** 오탈자·과장을 막는다.
- **도구 경계 명시**: 3D는 블렌더, 합성은 2D.
