# 07. 닉네임 + 아이콘 하나로 만드는 개인 아이덴트

| 도구 | ChatGPT Astra 단독 (모든 영상이 코드로 생성) |
| 결과 | 15초, 직접 만든 음악, 비트에 맞춘 편집, 문구는 모델이 작성 |

## 이런 영상

닉네임과 노란 꽃 아이콘만 정해 주고 나머지 문구·음악·모션은 모델이 채운 쫀득한 개인 브랜딩 영상.

## 재현 프롬프트

작성자는 원하는 느낌, 닉네임, 꽃 아이콘, 15초만 지정했다. 같은 요소로:

```
내 닉네임 "[닉네임]"을 소개하는 15초 모션그래픽 영상을 만들어줘.
- [노란 꽃] 아이콘을 상징으로 넣어줘
- 분위기: [예: 경쾌하고 쫀득한 모션], 컬러: [예: 노랑 + 검정]
- 음악은 직접 만들고, 편집은 비트에 딱딱 맞춰서
- 다른 문구는 네가 알아서 어울리게 채워줘
```

## 바꿔 쓸 곳

- 닉네임, 상징 아이콘, 분위기, 컬러. 작성자 조언: 원하는 분위기·리듬·컬러를 정확히 설명할수록 좋다.

## 잘 된 이유

- **고정할 것 두 개**(이름, 상징)만 주고 나머지는 위임해 모델의 편집 감각을 쓴다.
- "해줘"만으로도 마음에 드는 결과가 나와 조금만 다듬으면 된다.
