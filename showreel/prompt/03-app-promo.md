# 03. 앱 홍보 영상 (아이폰 광고 티저 톤)

| 항목 | 내용 |
| --- | --- |
| 원본·영상 | ▶ [@go_tworavel 스레드](https://www.threads.com/@go_tworavel/post/Ddq5DmME47e) (조회 11만, 좋아요 958) — 프롬프트는 작성자 답글 |
| 도구 | Claude Code Opus 5.5 단독 (앱 로그인·화면 캡처·무료 소스 탐색·작곡까지) |
| 결과 | 빠른 템포의 브랜드 스토리형 앱 광고 |

## 이런 영상

검은 화면 큰 글자 오프닝, 드롭에서 한 박에 한 단어, 실제 앱 화면과 무료 영상 소스, 직접 작곡한 음악, 브랜드 한 줄 + 로고로 끝.

## 재현 프롬프트

첫 요청(레퍼런스로 톤 잡기)과, 피드백을 합친 본 요청 두 단계다.

```
[유명 크리에이터]도 감탄할 만한 앱 홍보 영상을, 아이폰 광고 티저처럼 빠른 템포로 만들어줘.
```

```
우리 앱 [앱 이름/URL] 홍보 영상을 만들어줘.
- 기능 나열 말고, 이 앱이 주는 본질적 가치를 브랜드 스토리로
- 첫 1초 후킹이 가장 중요: 누구나 겪어 본 장면 하나로 시작
- 오프닝: 검은 화면에 큰 글자, 박자마다 쾅
- 템포는 빠르게. 드롭에서는 한 박자에 한 단어, 단어와 배경 영상을 맞춰서
- 앱 화면은 실제 화면만 (직접 열어서 캡처), 부족한 영상은 무료 소스에서 찾아서
- 배경음악은 촌스럽지 않게 직접 만들어서
- 마지막은 브랜드 한 줄 + 로고
- 만들기 전에 구성안부터 보여줘
```

## 다듬기 피드백

결과를 보고 짧게 고친다: "촌스러워", "후킹 약해", "템포 더 빠르게", "음악이 너무 감미로워".

## 잘 된 이유

- **레퍼런스 두 개**(사람 + 광고 장르)로 톤을 한 번에 전달.
- 무엇을 말할지(가치), 어떻게 시작할지(1초 후킹), 박자당 정보량(한 단어)을 정해 준다.
- **"실제 화면만"**으로 가짜 UI를 막는다.
- **구성안 먼저**: 방향을 싸게 고친다.
