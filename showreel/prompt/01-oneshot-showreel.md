# 01. 한 문장 원샷 쇼릴

| 항목 | 내용 |
| --- | --- |
| 원본·영상 | ▶ [@pinksoldiersvlog 스레드](https://www.threads.com/@pinksoldiersvlog/post/Ddt090_E5KV) (조회 2.8만, 좋아요 235) |
| 도구 | Claude Code Opus 5.5, 추론 높음 |
| 결과 | 한글 15초 모션그래픽 쇼릴, 원샷, 음악 포함, 외부 에셋 없음 |

## 이런 영상

모델이 스스로 구성·색·음악을 정한 "디자이너 자기소개" 쇼릴. 결과 스타일은 매번 다르다.

## 재현 프롬프트

원문은 한 문장이다. 같은 요소로 다시 쓰면:

```
당신이 얼마나 뛰어난 모션그래픽 디자이너인지 증명하는, 역동적인 한글 15초 모션그래픽 영상을 만들어 주세요.
이력서에 붙이는 쇼릴처럼요. 전력을 다해 주세요.
```

## 바꿔 쓸 곳

- 언어(`한글`)와 길이(`15초`)만 바꾼다. 나머지를 덧붙이면 오히려 모델의 선택 폭이 줄어든다.
- 결과를 고정하고 싶다면 [00](00-code-showreel.md)이나 [02](02-3d-brand-showreel.md)로 넘어간다.

## 잘 된 이유

- **역할 부여**: "당신이 얼마나 뛰어난지 증명" → 요구를 채우는 게 아니라 실력을 보여주려 한다.
- **장르 한 단어**: "이력서용 쇼릴"이 짧게·임팩트·비트 싱크라는 관습을 통째로 전달한다.
- **최소 고정**: 길이·언어·톤만 고정하고 나머지는 맡긴다.
- **노력 수준**: "전력을 다해"가 추론 높음 설정과 맞물려 초안에서 멈추지 않게 한다.
