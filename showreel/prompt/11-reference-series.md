## 이런 영상

이미 만든 모션그래픽 몇 편과 같은 톤·레이아웃·움직임을 유지하면서 주제만 새로 바꾼 짧은 설명 영상. 시리즈를 이어 갈 때 쓴다.

## 재현 프롬프트

작성자는 프롬프트 원문 대신 방법(레퍼런스 → 생성 → 디렉팅)을 공유했다. 그 방법대로 쓰면:

```
첨부한 영상 [N]편은 내가 만든 모션그래픽 시리즈야.
먼저 이 영상들의 공통 시각 문법을 정리해 줘: 색, 폰트, 레이아웃, 전환 방식, 움직임 속도, 음악 톤.
그다음 같은 문법으로 새 편을 만들어 줘.
- 주제: [새 주제, 예: AI는 문장을 어떻게 처리할까?]
- 길이: [길이]초, 비율: [비율]
- 설명형: 한 장면에 개념 하나, 도식으로 보여 주기
- 정리한 시각 문법에서 벗어나는 요소는 넣지 말 것
```

## 다듬기 피드백

첫 결과도 괜찮지만 몇 번의 디렉팅이 필요했다. 레퍼런스와 다른 부분을 짚어 "이 장면은 2편처럼 전환해줘"처럼 구체적인 편을 가리키면 빠르다.

## 잘 된 이유

- **스타일 설명 대신 내 작업을 준다**: 시리즈의 일관성이 저절로 유지된다.
- **문법을 먼저 정리하게 한다**: 모델이 무엇을 따를지 명시적으로 합의한 뒤 만든다.
- 매번 처음부터 만드는 것보다 제작 시간이 크게 준다. 교육형·연재형 콘텐츠에 특히 맞는다.
