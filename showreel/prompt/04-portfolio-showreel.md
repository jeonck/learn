# 04. 포트폴리오 링크로 만드는 자기소개 쇼릴

| 항목 | 내용 |
| --- | --- |
| 원본·영상 | ▶ [@doeun_company 스레드](https://www.threads.com/@doeun_company/post/DdwJM-yCI5u) |
| 도구 | Claude Opus 5.5 (HTML/CSS/JS 애니메이션 → 프레임 캡처 → 60fps) |
| 결과 | 경력·수상·프로젝트 이미지 90여 장을 쓴 포트폴리오 쇼릴, 합성 음악 |

## 이런 영상

노션 포트폴리오의 문장과 이미지로 컨셉을 잡고, 타이포·전환·3D 카드 월·파티클을 코드로 만든 쇼릴.

## 재현 프롬프트

원 요청은 "포트폴리오 링크 + 나를 소개하는 쇼릴" 한 줄이다. 결과 파이프라인까지 명시하면:

```
[포트폴리오 URL]을 직접 읽고 나를 소개하는 모션그래픽 쇼릴을 만들어줘.
- 경력, 수상, 프로젝트 이미지를 모으고, 포트폴리오 안의 문장으로 컨셉을 잡을 것
- 포트폴리오에 없는 사실은 쓰지 말 것
- 타이포, 전환, 3D 카드 월, 파티클을 HTML/CSS/JS 애니메이션으로 만들고
  브라우저에서 프레임 단위로 캡처해 60fps MP4로 렌더
- 빠른 움직임에는 프레임마다 여러 장을 겹쳐 모션 블러
- 배경음악과 효과음(킥, 신스, 타이핑, 임팩트)은 코드로 합성해 컷과 박자를 맞출 것
```

## 바꿔 쓸 곳

- 포트폴리오 URL(노션, 비핸스, 개인 사이트). 로그인이 필요한 곳은 PDF로 내보내 첨부한다.

## 잘 된 이유

- **내용은 자료로, 형식은 한 줄로**: 사실이 틀릴 틈이 적다.
- 결과 파이프라인이 [00](00-code-showreel.md)과 같다. Opus 5.5가 쇼릴을 만들 때 스스로 고르는 표준 구조다.
