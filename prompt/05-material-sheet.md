## 이런 영상

한 장의 재료 시트에 있는 캐릭터·소품·글자가 따로 떨어져 나와 움직이는 귀여운 데모.

## 재현 프롬프트

1단계, 재료 시트 이미지:

```
[주제] 모션그래픽에 쓸 재료 시트를 만들어줘.
- 가로 6칸 × 세로 6칸 격자
- 주제에 맞는 캐릭터, 소품, 타이포, 장식을 일관된 그림체와 색감으로
- 그림체: [예: 종이 콜라주 / 플랫 벡터 / 크레용]
- 각 재료는 따로 잘라 움직일 수 있게, 서로 겹치거나 잘리지 않도록 여백을 두고 배치
```

2단계, 영상:

```
이 재료들로 [길이]초 모션그래픽 데모 영상을 만들어줘. 음악 포함.
```

## 다듬기 피드백

원하는 결과에 맞추려면 두세 번은 수정 요청을 주고받는다.

## 잘 된 이유

- 스타일을 말 대신 **이미지로 고정**한다. "예쁘게, 감각적으로"를 반복할 필요가 없다.
- **여백 두고 분리 배치**라 요소별 애니메이션이 쉽다.
- 수정 왕복이 줄어 토큰·크레딧이 절약된다.
