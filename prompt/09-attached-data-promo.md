# 09. 자료 첨부형 홍보 영상

| 결과 | 참고 URL·첨부 자료로 만든 사람·행사·강의 소개 모션그래픽 |

## 이런 영상

알릴 대상(사람, 강의, 가게, 행사)의 자료를 주면 후킹 문장 → 핵심 메시지 → 근거 → 행동 안내 순서로 소개하는 영상.
플랫폼(릴스, 유튜브, 행사장 화면)에 맞춰 비율과 길이를 고른다.

## 재현 프롬프트

```
[알릴 대상]을 소개하는 [30]초 모션그래픽 영상을 만들어 주세요.

[1. 자료 파악]
- 아래 자료를 먼저 읽고 핵심을 파악해 주세요.
· [참고 URL]
· [첨부 자료: 이미지, 로고, 소개글, 후기 등]
- 첨부 자료가 웹 정보보다 우선입니다.
- 확인되지 않은 내용은 지어내지 말고, 부족한 자료가 무엇인지 먼저 알려 주세요.
- 장면별 문구를 먼저 짧게 정리해 보여 준 뒤 제작해 주세요.

[2. 목적과 대상]
- 이 영상을 볼 사람: [타깃 시청자]
- 보고 나서 하길 바라는 행동: [구매 / 신청 / 참여 / 팔로우 등]
- 올릴 곳: [인스타그램 릴스 / 유튜브 / 행사장 화면 등]

[3. 영상 구성]
- 첫 2초 안에 시선을 붙잡는 한 문장
- 핵심 메시지와 다른 것과의 차이
- 믿을 만한 근거(만든 사람의 이력, 수치, 추천이나 후기)
- 마지막 장면: 이름, 로고나 대표 이미지, 행동 안내(날짜, 링크, 신청 방법 등)

[4. 표현 원칙]
- 인용문과 확정된 문구는 원문 그대로 쓸 것
- 색과 분위기는 [브랜드 색 / 대표 이미지]에서 가져올 것
- 한 화면에 한 메시지, 글자끼리 겹치지 않게
- 자막은 휴대폰 화면에서도 읽힐 크기로
- 톤: [밝고 경쾌하게 / 차분하고 진지하게 / 고급스럽게 등]

[5. 사운드]
- 장면 전환과 강조 순간에 맞춘 배경음악과 효과음
- 저작권 문제가 없는 음원만 사용

[6. 결과물]
- [1080×1920(세로) / 1920×1080(가로) / 1080×1080(정사각)], 30fps, [15]초 MP4 파일
- 전달 전에 주요 장면을 캡처해 글자 겹침, 잘림, 오탈자, 사실 오류를 직접 확인할 것
```

## 바꿔 쓸 곳

- 대괄호 칸 전부: 알릴 대상, 길이, 참고 URL, 첨부 자료, 시청자, 원하는 행동, 올릴 곳, 브랜드 색, 톤, 비율.
- 첨부 자료가 충분할수록 결과가 정확하다. 로고와 대표 이미지는 꼭 넣는다.

## 잘 된 이유

- **자료 우선 + 지어내지 않기**: 첨부 자료가 웹보다 우선이고, 부족한 자료를 먼저 묻게 해서 사실 오류를 막는다.
- **문구 먼저 확인**: 장면별 문구를 먼저 보여 주게 해 방향을 싸게 고친다([03](03-app-promo.md)의 구성안 먼저와 같다).
- **목적과 행동을 명시**: 누가 보고 무엇을 하길 바라는지가 구성(후킹 → 차별점 → 근거 → 행동 안내)을 결정한다.
- **모바일 가독성 기준**: 한 화면 한 메시지, 휴대폰에서 읽히는 자막 크기.
- **전달 전 자체 검수**: 겹침·잘림·오탈자·사실 오류를 캡처로 확인하게 한다.
